# Olist E-Commerce Analytics | HVIA Trial Task

An exploratory data analytics and business opportunity project using the **public Olist Brazilian E-Commerce dataset**. Prepared as a training project to investigate delivery performance, customer experience, and potential data-driven improvements.

## Project contents
- `Olist_HVIA_Analysis_Notebook.ipynb` — Python analysis notebook.
- `Olist_HVIA_Analysis_Report.docx` — written analysis and recommendations.
- `Olist_HVIA_Presentation.pptx` — project presentation.

## Tools and skills
Python, Pandas, SQL-oriented relational analysis, exploratory data analysis, business analytics, and data visualization.

## How to run
1. Download the public **Brazilian E-Commerce Public Dataset by Olist** from Kaggle.
2. Place the original CSV files in the paths expected by the notebook (review the notebook's data-loading cell).
3. Install notebook dependencies and run the cells in order.

**Note:** The dataset files are not included in this repository. The historical dataset covers 2016–2018. Business proposals and forecasts described in the presentation are recommendations, not verified production outcomes. This repository is a training/portfolio project and is not an official Olist or HVIA product.
